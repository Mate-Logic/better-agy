# Home (landing)

Scope: `src/components/Home.astro` (EN `/`, ES `/es/`). Mode: Persuade.

Audience and job: agy users deciding which plugins to install. Action: pick plugins and copy the install command or prompt. Proof: the terminal demos and Sub Meter's live bar.

## Direction contract

THESIS: the page is a sibling of antigravity.google: white (or near-black in dark mode) ground, a cursor-reactive field of Google-coloured dashes, huge tightly tracked Google Sans Flex headlines, pill buttons. It refuses the dark terminal-as-page look the site had.

OWN-WORLD: antigravity.google tokens: surface #fff / #121317, containers #f8f9fc and #eff2f7, ink #121317, secondary #45474d, pills (black primary, tonal secondary), 24px radius panels, black terminal panels with particles, line icons in circles, a giant wordmark in the footer. Google Sans Flex for words, Google Sans Code for terminal output.

STORY: the visitor sees "a better Antigravity CLI", the NEW bar announces Sub Meter, the Sub Meter panel shows the bar moving, the plugin grid shows each improvement with real output, and the install terminal types the exact command they copy.

FIRST VIEWPORT: sticky nav (glyph + wordmark, links, language, black Install pill), announcement bar (NEW · Sub Meter), centred particle ring with glyph lockup, two-line headline at ~100px, subline, tonal "See plugins" plus black "Install".

FORM: pinned by the user, seed: none (pinned): "basa completamente en la pagina de https://antigravity.google/", "No tanto efecto glass, sino el como es la pagina de antigravity.google en si".
